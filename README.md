# 3D Printing Operations Analytics Dashboard

## Overview
An interactive Power BI dashboard designed to analyze the financial and operational performance of a 3D printing business.

## Objectives
- Track revenue, profit, and profit margin.
- Monitor order performance and success rates.
- Analyze printing duration and production efficiency.
- Support data-driven business decisions through interactive visualizations.

## Tools & Technologies
- Microsoft Power BI
- DAX
- Data Analysis and Visualization

## Key Metrics
- Total Revenue
- Total Profit
- Profit Margin
- Successful Orders
- Average Print Duration

## Project Files
- `3DPrintingDashboard.pbix` — Power BI dashboard file.

## How to View
Download the `.pbix` file and open it using Power BI Desktop. Power BI Desktop is required to interact with and modify the report.

## Notes
This project demonstrates the application of business intelligence and data visualization to operational and financial performance analysis.
